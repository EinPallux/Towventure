## [Unreleased]

### Added
- **Phase 2 — The Hoard (in progress):** completing the build engine.
  - **Biomes 2–5 — the 50-floor climb (CONTENT §4/§4.1, BALANCE §4):** the tower no longer loops the Gatehouse. Floors 11–50 now run the **Gardens → Archive → Foundry → Chapel**, each with 3 authored regulars, an elite, and a boss, ending on the **Prior of Teeth** (floor 50) — the named mid-game wall and this increment's exit criterion. Three anti-autopilot walls are modelled in the sim directly, gated behind optional enemy fields so **every Phase 1/early-Phase 2 golden hash is unchanged** (the golden diff is purely additive): **crit-immunity** that even Shock cannot pierce (The Unshelved), a **DoT that heals** its bearer (Cinder Widow ← Burn — Burn *loses* to her), and a **status-density self-heal** (the Prior heals 3%/s, halved once 10+ statuses sit on him). Regulars carry the implementable status checks — Bramble Shambler/Root-Queen Venom, Bloodthorn Bleed, Marginalia Weaken, Slag Imp Burn, Ash Chorister Chill; Vow-Forged Sentinel hardens over time. Mechanics needing vocabulary the sim/run layers don't have yet (weapon-copy, silence, gold-bribe, death-blast, lifesteal/speed caps, summons, the Colossus's Armor-shed + stagger) are labelled *deferred* on each enemy and in the docs, and each still fights as an honest stat check. Client palettes for all four biomes (verdigris/candle-ivory/ember-orange/bone-&-wine). Harness curve check: deaths now spread across floors 20–60 (was a Gatehouse loop), peaking on the Prior — median first death floors 40–50 for the greedy fuse-and-equip bot, with the floor-50 wall landing as designed.
  - **Duelist & Arcanist classes playable (BALANCE §2, CONTENT §1):** all three classes now compile and climb, with distinct harness death-floor profiles (Vanguard sturdy/consistent, Duelist deepest via the crit+Haste snowball, Arcanist high-variance/squishy). Added their base stats, start kits, and relics (Twin-Fang Oath, Cinderheart) plus the items those kits need — Apprentice Sparkrod (now expressible thanks to Shock) and the Adrenal Vial. The relics are modelled with the current effect vocabulary; the exact CONTENT mechanics (per-weapon alternation, effect-recast, status-damage +15%) are noted on each relic and await deferred ops. Protocol class enum opened to all three; the harness profiles every class; the Gate gains a class picker (verified in-browser — a Duelist starts with its full kit).
  - **Tag synergies (2/4/6 thresholds, CONTENT §2.2):** the build compiler counts each tag across the 8 equip slots and injects the met thresholds' mods/effects into the hero — e.g. Bulwark (2) +8 Armor, Bulwark (4) on-block Ward, Wild (4) heal-on-kill, Frost (4) Chill→Shock, Wild (6) low-HP Speed+damage spike. The thresholds needing new ops (per-weapon-tag speed, status-effectiveness/damage modifiers, next-hit buffers, DoT-crit, stealth) are catalogued in a `DEFERRED` map. The hero screen gains a **build tag meter** showing each tag's count with lit 2/4/6 pips. A fresh Vanguard already trips Bulwark (2) — the Pot-Helm and Sigil are both Bulwark.
  - **Awakened (★3) fusion lines activate:** the build compiler now gates both effect lines and stat modifiers by `minStar`, so fusing an item to ★3 unlocks its second line. Transcribed the doc-authored Awakened lines that fit the current effect vocabulary onto seven anchor items (e.g. Rusty Cleaver +10% Crit, Sawtooth Dirk `OnCrit → +2 Bleed`, Fangback Spear `OnEnemyDeath → Haste`, Chime `OnHurt → Chill the attacker`). Zenith (★5) transforms and the Awakened lines needing new ops (per-Armor damage, next-hit buffers, detonate/consume) are deferred with a note.
  - **Sim completion — all 10 statuses + the full trigger vocabulary (BALANCE §3, GDD §3.3):** added Venom (never-expiring ramping DoT), Shock (next hit can't miss and is a guaranteed crit, consumed), Weaken (−5%/stack outgoing damage), Sunder (−3 Armor/stack, can push Armor negative to −15), and Haste (+5%/stack Speed); plus the `OnStatusApplied(X)` and `OnEnemyDeath` triggers and a `buffSpeedPct` effect op. The five new statuses are **appended** to the resolution order so every Phase 1 golden hash is unchanged (verified: the golden diff is purely additive). Seven new golden scenarios pin the new mechanics, and explicit tests lock Shock-forces-crit-through-dodge and Venom-ramps. This is the engine foundation the rest of Phase 2 (the ~120 items, Duelist/Arcanist, biomes 2–5) builds on.
- **Phase 1 — The Heartbeat (code complete; staging deploy pending a VPS):** the online vertical slice.
  - **Monorepo & tooling:** pnpm workspaces, TypeScript strict, ESLint (with a determinism tripwire banning `Math.random`/`Date` in the sim/run hot path), Prettier, Vitest. Dev commands live: `pnpm dev · test · typecheck · lint · format · goldens:update · harness · build`.
  - **`packages/shared` — the deterministic heart:** xoshiro128\*\* seeded RNG + FNV-1a event-log hash (integer math only); a 10 Hz tick engine covering the nine Phase 1 triggers, five statuses (Bleed/Burn/Chill/Regen/Ward), Armor/crit/dodge/lifesteal/thorns, and Doomfall; a 16-scenario **golden replay suite** with committed hashes. Run reducers: doors, seeded loot/gold, equip (2-hand + trinket resolution), **fusion ★1→★5 stat scaling**, sell, and the Wandering Merchant with the Requested-Copy valve + Epic pity. Content: the Vanguard + Bulwark Sigil, ~17 anchor items across every rarity/slot, the Gatehouse roster + Toll-Keeper boss; zod protocol schemas.
  - **`packages/server`:** Fastify 5 + Drizzle + Postgres 16, argon2id auth with DB sessions, the single `/api/run/command` mutation route (shared reducers, state-version optimistic concurrency, run-event audit log), server-authoritative fights (seed drawn server-side, only seed+hash shipped), the ledger-only Honor economy, and the global ladder. Schema v1 + forward-only migrator; `/healthz`; helmet + per-route rate limits.
  - **`packages/client`:** Vite + React + Zustand + Three.js, all-procedural "Lanternlight Gloom" (zero binary assets) — The Gate, the fight diorama with replay-from-seed playback (HP bars, damage numbers, Doomfall vignette, 1×/2×/skip), the hero screen (equip/backpack/fuse), doors/reward/shop, the death ritual, and the ladder. Bundle 182 KB gz.
  - **`packages/harness`:** headless balance CLI over the sim (death-floor distributions); Ops: docker-compose (caddy/app/postgres/backup), Dockerfile, nightly `pg_dump` with rotation; CI (typecheck → lint → format → unit + golden + Postgres integration tests → harness smoke → build).
