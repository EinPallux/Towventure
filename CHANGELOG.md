## [Unreleased]

### Added
- **Phase 2 — The Hoard (in progress):** completing the build engine.
  - **Sim completion — all 10 statuses + the full trigger vocabulary (BALANCE §3, GDD §3.3):** added Venom (never-expiring ramping DoT), Shock (next hit can't miss and is a guaranteed crit, consumed), Weaken (−5%/stack outgoing damage), Sunder (−3 Armor/stack, can push Armor negative to −15), and Haste (+5%/stack Speed); plus the `OnStatusApplied(X)` and `OnEnemyDeath` triggers and a `buffSpeedPct` effect op. The five new statuses are **appended** to the resolution order so every Phase 1 golden hash is unchanged (verified: the golden diff is purely additive). Seven new golden scenarios pin the new mechanics, and explicit tests lock Shock-forces-crit-through-dodge and Venom-ramps. This is the engine foundation the rest of Phase 2 (the ~120 items, Duelist/Arcanist, biomes 2–5) builds on.
- **Phase 1 — The Heartbeat (code complete; staging deploy pending a VPS):** the online vertical slice.
  - **Monorepo & tooling:** pnpm workspaces, TypeScript strict, ESLint (with a determinism tripwire banning `Math.random`/`Date` in the sim/run hot path), Prettier, Vitest. Dev commands live: `pnpm dev · test · typecheck · lint · format · goldens:update · harness · build`.
  - **`packages/shared` — the deterministic heart:** xoshiro128\*\* seeded RNG + FNV-1a event-log hash (integer math only); a 10 Hz tick engine covering the nine Phase 1 triggers, five statuses (Bleed/Burn/Chill/Regen/Ward), Armor/crit/dodge/lifesteal/thorns, and Doomfall; a 16-scenario **golden replay suite** with committed hashes. Run reducers: doors, seeded loot/gold, equip (2-hand + trinket resolution), **fusion ★1→★5 stat scaling**, sell, and the Wandering Merchant with the Requested-Copy valve + Epic pity. Content: the Vanguard + Bulwark Sigil, ~17 anchor items across every rarity/slot, the Gatehouse roster + Toll-Keeper boss; zod protocol schemas.
  - **`packages/server`:** Fastify 5 + Drizzle + Postgres 16, argon2id auth with DB sessions, the single `/api/run/command` mutation route (shared reducers, state-version optimistic concurrency, run-event audit log), server-authoritative fights (seed drawn server-side, only seed+hash shipped), the ledger-only Honor economy, and the global ladder. Schema v1 + forward-only migrator; `/healthz`; helmet + per-route rate limits.
  - **`packages/client`:** Vite + React + Zustand + Three.js, all-procedural "Lanternlight Gloom" (zero binary assets) — The Gate, the fight diorama with replay-from-seed playback (HP bars, damage numbers, Doomfall vignette, 1×/2×/skip), the hero screen (equip/backpack/fuse), doors/reward/shop, the death ritual, and the ladder. Bundle 182 KB gz.
  - **`packages/harness`:** headless balance CLI over the sim (death-floor distributions); Ops: docker-compose (caddy/app/postgres/backup), Dockerfile, nightly `pg_dump` with rotation; CI (typecheck → lint → format → unit + golden + Postgres integration tests → harness smoke → build).
- **Phase 0 — The Plan:** complete planning baseline.
